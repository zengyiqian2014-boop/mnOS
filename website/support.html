SUPPORT / 系统支持

有问题，随时反馈。

如果遇到 Bug、安装或启动异常、硬件兼容性问题，可以发邮件告诉我们。自研 mnOS 和 Linux Edition 均使用这个反馈入口。

report.mnos@proton.me

这些信息能帮助复现问题

  • 系统版本、Full / Lite、AMD64 / ARM64。
  • 设备型号；使用虚拟机时，附软件名称、版本和虚拟化方式。
  • 出现问题前的操作、实际结果和预期结果。
  • 相关截图或日志片段；不必发送整份磁盘或所有日志。

发送前请检查附件，不要包含密码、令牌、验证器密钥或恢复码。此页面不会自动收集或上传诊断信息。

从系统内找到我们

Linux Edition：系统设置 → 系统支持，或运行 mnos-support；help -cn support 查看中文说明。自研 mnOS：系统设置 → Support / H，或在原生终端输入 support -cn。

System support

Report bugs and hardware compatibility issues at any time to report.mnos@proton.me. Include your version, edition, architecture, device or VM model, and reproduction steps. Review screenshots and logs before sharing; never include passwords, tokens or recovery codes.
