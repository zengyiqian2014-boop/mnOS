Linux 模拟环境

需要时，打开一个窗口。

通过自研软件模拟器，在 mnOS 内运行真实 Linux / BusyBox 客体。默认关闭；用户确认后启动，也能随时在设置中关闭。

  • 当前支持 RV64 Linux 控制台程序
  • 暂停、恢复、停止，空闲时让出执行
  • 关闭模拟会清除客体内存和临时文件

当前模拟环境尚不支持 APT、网络或 Firefox / VS Code 等 GUI 应用。完整 Linux 系统的 ISO 在独立页面提供。

什么时候模拟，由你决定

需要时打开。结束时关闭。

01

默认关闭。

日常启动进入自研桌面。首次打开受支持的 Linux 控制台程序时，系统询问是否开启 Linux 模拟。

02

随时控制。

通过设置或原生命令暂停、恢复和停止模拟。关闭模拟会清除客体内存与临时文件，主系统继续运行。

03

安装镜像分开。

自研 mnOS ISO 和独立 Linux 系统 ISO 分别提供。后者有自己的下载页，安装后直接运行 Linux 内核。
