Native Edition

每一层，都亲手构建。

由 C 与汇编编写的 mnOS 内核，连接原创图形桌面、文件系统与命令环境。走进操作系统的内部，也参与它的成长。

  • 原生窗口、文件浏览、编辑器与终端
  • 图形安装，文件和设置保存在 MNFS
  • 按需启用的 Linux / BusyBox 控制台客体

开发预览：Linux 客体当前支持 RV64 控制台程序，尚不支持 APT、网络或 Firefox / VS Code 等 GUI 应用。

Linux Edition

熟悉的生态，即刻开工。

以 Debian Linux 和 Xfce 为基础，集成 mnOS 工具中心与系统管理。浏览、开发、安全实验，在一个工作空间内完成。

  • Firefox、VS Code 与 C / C++ 开发工具
  • 真实 APT 软件包管理和 Linux 命令
  • 分类工具中心、CTF 工作台与系统设置

Linux Edition 使用上游 Linux 内核和桌面组件。它与 Native Edition 分别安装，功能和驱动支持范围不同。

01

完整，或轻装。

Full 面向完整工具环境；Lite 面向精简的 C / C++ 工作流，不包含 Python 和额外登录因素。已发布的组合在下载区列出。

02

权限，清清楚楚。

日常应用使用普通账号。管理操作再提权；安装时可以选择是否为该账号开放特权网络工具。

03

更新，有据可查。

更新命令先验证签名版本索引，再交给 APT。组件版本保留，便于明确选择回退；这不等于整盘系统快照。
