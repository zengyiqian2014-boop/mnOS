Linux 模拟环境

在 mnOS 内运行 Linux 客体。

v0.10 Full 离线安装包内含 Linux 6.12、Debian riscv64、APT、X11、C++ 应用中心，以及 Firefox ESR、Thunar 和 Mousepad。Linux 模拟默认关闭，启动前由你确认。

  • 在客体中安装 riscv64 / all 软件包，运行 X11 程序
  • 暂停、恢复、停止，空闲时让出执行
  • 个人数据盘保存软件与文件；停止前先执行 poweroff

这是单核 RV64GC 软件解释器，没有硬件虚拟化或 3D 加速。随附 Firefox ESR 使用 Debian riscv64 构建；不能直接运行 AMD64 / ARM64 的 DEB，包括官方 VS Code 安装包，这些软件请使用独立 Linux 版。旧 USB 驱动预览 ISO 不含本次应用环境。

模拟环境管理

启动、暂停、恢复和停止。

01

启动前确认

日常启动进入自研桌面。首次打开受支持的 Linux 应用时，系统询问是否开启 Linux 模拟。

02

运行状态控制

通过设置或原生命令暂停、恢复和停止模拟。先在客体中执行 poweroff 保存数据，再停止模拟；客体内存会被清除并回收，主系统继续运行。

03

独立 Linux 系统

自研 mnOS ISO 和独立 Linux 系统 ISO 分别提供。后者有自己的下载页，安装后直接运行 Linux 内核。
