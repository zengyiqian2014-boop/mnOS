mnOS Desktop 0.4 Preview 2 修复编辑器把比例字体放进固定字符格导致的异常字距。正文按实际字宽排版；光标、鼠标定位、换行和方向键使用相同的布局数据。终端改用真正的等宽字体。

七个应用现在各有独立的原创图标，在桌面、应用菜单、标题栏和任务栏显示。图标按目标尺寸生成抗锯齿像素，窗口圆角、阴影和任务栏布局一并调整，长名称按可用宽度显示。字体／图标构建器改用 C，镜像中没有额外图形库或脚本运行时。

字库扩展到 **49,776 个 Unicode 码位**，覆盖完整可打印 ASCII、中日韩文、扩展拉丁字母及常用符号；UTF-8 支持 1–4 字节，缺字和非法序列使用替代字符。压缩字库由 C 解码并检查长度。`kernel fonts` 查看字库信息，`kernel unicode` 显示实际多语言样例。尚无输入法、复杂文字塑形或完整 Unicode 字符覆盖，键盘文字输入目前仍限 ASCII。

`kernel <指令> [对象]` 统一调用真实内核、文件、进程及账号操作；新增安全状态、字体查询、磁盘状态查询等入口。`help` 默认英文，`help -cn` 中文；`help 命令` / `help -cn 命令` 逐条显示用途、语法、权限、示例和错误条件，`all` 展开全部。Tab 补全命令和常用参数，上下键翻阅最多 512 行输出。查询和个人操作无需 root，卷管理检查 root；错误参数不会执行卷修改，重启／关机需要本地确认。

AMD64、ARM64 各下载一份 ISO 即可；镜像安装后直接启动 mnOS 自研内核与原生桌面。

已集成：应用菜单与搜索、多窗口、文件浏览／创建／删除、文本编辑器、终端、系统监视、设备信息、壁纸与显示设置、普通用户／root 认证、持久化文件和个人设置。内核、桌面及安装器使用 C／汇编；镜像没有 Linux、Xfce 或 Python 运行时。

安装器进入图形界面，选择磁盘、确认清空整盘并输入 `ERASE`，安装完成后移除 ISO，从磁盘启动。账号在首次启动创建。**`help` 默认英文；`help -cn` 为中文。**

发布前在 AMD64 OVMF/IDE 和 ARM64 UEFI/FDT/VirtIO-MMIO QEMU 中实际完成空盘安装、移除 ISO 启动、键盘／鼠标操作、鼠标定位插字、方向键／退格编辑、文件保存、再次重启后账号／文件／设置恢复和权限拒绝检查。字体布局通过 ASan/UBSan 检查，包含窄／宽字母、UTF-8、Tab、换行与光标位置。取消安装会检查磁盘未写入。发布附源码、校验、日志和实际桌面／编辑器／终端／应用菜单截图；ISO 是本次成功验证的原始产物。

这是基础原生 GUI 的开发预览版：桌面服务仍在内核内；Firefox、VS Code、Linux 工具、APFS、AHCI/NVMe、USB、网络／Wi-Fi、音频和 GPU 加速尚未完成，不能当作已全部兼容的日常系统。UTM 使用匹配设备的 QEMU 后端，Apple Virtualization.framework 未验证。完整配置、账号／编辑器现有限制和安装说明见仓库 `native/DESKTOP.md`。

旧 v2.0 Linux/Xfce 安装包继续独立归档，不是本版本的底层或默认桌面。
