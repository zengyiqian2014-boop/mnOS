mnOS 集成工具安装包
==================

按 CPU 架构选择一份 ISO，离线安装时一起写入桌面、Firefox ESR、官方 VS Code、
nano、开发编译环境、CTF/网络/系统工具、驱动固件和自研内核入口。
AMD64 面向 Intel/AMD 64 位，ARM64 面向 AArch64 UEFI；每种架构同一份镜像
包含虚拟机和常见硬件支持，未测试的硬件仍不能承诺兼容。

默认桌面工具环境使用 Debian 13/Linux 6.12 LTS/Xfce。自研 C/汇编内核是
另一个引导入口，有自己的原生 GUI、文件系统和账号；不支持 Linux 应用 ABI。
不要把 Firefox/VS Code 说成已运行在自研内核上。

完整英文命令手册：help
完整中文命令手册：help -cn
具体章节：help -cn code / firefox / packages / build / network / kernel
具体软件：help 工具名（随软件安装的上游手册，语言取决于软件）
自研入口：help -cn all，逐条列出实际实现的原生命令。

图形安装器先选磁盘、创建普通账号和网络权限模式，再确认整盘清空。
当前是自动整盘分区安装，不支持保留旧系统、手动分区或安装时加密。
安装完成关机、移除 ISO、从硬盘启动。没有默认密码，直接 root 登录锁定。
日常应用、个人文件和桌面设置使用普通用户，系统修改使用 sudo/Polkit。
Live 会话写入是临时的，只有安装到硬盘后的个人文件和设置才持久保存。

工具环境不安装 Java SDK。Python 仅为已选第三方工具的必需依赖保留。
系统中心、安装界面、内核管理、软件管理和命令帮助使用编译的 C/C++。
详细工具/包版本在 /usr/share/doc/mnos/packages.tsv。

软件管理：mnos-pkg list/search/show/check；管理员显式使用 sudo mnos-pkg
update/install/remove/upgrade。保留签名校验、依赖解析及 APT 的确认提示。
不会开机自动扫描网络，不会自动为浏览器或编辑器提权，不关闭应用沙箱。

UTM 先使用 QEMU 后端：取消“使用 Apple 虚拟化”，ARM64 主机运行 ARM64
来宾仍可在 QEMU 设置中启用 HVF CPU 加速。Apple Virtualization.framework
与 QEMU/HVF 是不同后端，前者目前未验证。原生内核未签名，需要关闭
Secure Boot；Linux 工具入口使用 Debian 的签名引导链。

原生文档和源码：/usr/src/mnos-native。
原生 MNFS 目前支持 ATA PIO（AMD64）或 VirtIO-MMIO（ARM64）磁盘，
未识别到 MNFS 卷时账号和文件只在内存中；不要把 Linux ext4 分区当 MNFS。
